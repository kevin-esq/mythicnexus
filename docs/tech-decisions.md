# Technical decisions

| Area                | Choice                                         | Notes                                                                                                                                                                                                             |
| ------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Monorepo            | pnpm workspaces + Turborepo                    | Single lockfile; cacheable `build` / `dev` tasks                                                                                                                                                                  |
| Frontend            | Next.js (App Router), TypeScript, Tailwind CSS | UI components can adopt shadcn/ui incrementally                                                                                                                                                                   |
| Data fetching       | TanStack Query                                 | Client cache and server-state patterns for API calls                                                                                                                                                              |
| Backend             | ASP.NET Core 9, minimal APIs                   | Layered projects under `apps/api/src/`; modular `Modules/*` on the host ([ADR 003](./adr/003-aspnet-modular-monolith.md), [ADR 005](./adr/005-backend-solution-layout.md))                                        |
| Testing (backend)   | xUnit + `WebApplicationFactory`                | Projects under `apps/api/tests/`; `Testing` + `appsettings.Testing.json` for host integration tests ([ADR 004](./adr/004-backend-testing-layout.md))                                                             |
| Persistence         | EF Core 9 + Npgsql                             | PostgreSQL only; no SQLite                                                                                                                                                                                        |
| Validation          | FluentValidation                               | Request validators as features grow                                                                                                                                                                               |
| Local orchestration | **One** `docker-compose.yml` at repo root      | Postgres (and future shared deps like Redis) in one place; `docker compose up -d postgres`. Avoid per-app compose unless an app is developed/deployed as an isolated stack.                                       |
| Local DB            | Docker Compose, `postgres:16`                  | Default dev connection in `appsettings.Development.json`; override with `apps/api/.env`. Apply schema with `dotnet ef database update` — see [docs/database-local.md](docs/database-local.md). Remote Supabase uses the same API/EF path with a different connection string. |
| Local configuration | Next: `.env.local`; API: `.env` + JSON         | Next reads `.env*` natively; API loads optional `apps/api/.env` before host startup via `DotNetEnv` (see `LocalEnvLoader`)                                                                                        |

Open items: refresh-token or session hardening, CI workflow shape, hosting targets.
